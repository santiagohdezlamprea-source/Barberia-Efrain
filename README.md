# Barbería Don Efraín

Página para una barbería de barrio (ficticia) en Galerías, Bogotá.

🔗 **Demo:** https://santiagohdezlamprea-source.github.io/barberia-don-efrain/

## Por qué la hice

Quería practicar con un negocio que se pareciera a los del barrio, no a una marca grande.
La mayoría de barberías por acá no tienen página, solo un Instagram, y la gente reserva por WhatsApp.
Por eso la página lleva directo a eso.

## Qué tiene

- Indicador de **"Abierto / Cerrado ahora"** que se calcula con el horario y la hora del visitante
- Lista de precios estilo carta de barbería
- Formulario de reserva que arma el mensaje de WhatsApp (barbero, servicio y día)
- Validación para no reservar en días pasados ni en domingo
- Se adapta a celular

## Tecnologías

HTML, CSS y JavaScript, sin frameworks. Publicada con GitHub Pages.
